# 公文 PDF 快合 HTML × Office v0.2.0 — 測試發行

## 本次修正
- 可直接拖入公文ZIP，或多份PDF／DOCX／ODT／ODS／PPTX等檔案，追加、上移、下移、刪除及清空。
- 內建離線PDF.js解析主文PDF文字，嘗試辨識**來文機關、民國發文日期、發文字號**；辨識成功時使用「機關公文及其附件.pdf」命名，可選擇完整日期文號格式；失敗則不假裝辨識成功，顯示待確認並可自行修改。
- OfficeBridge.vbs新增每個Office操作的階段及錯誤碼（啟動／巨集防護設定／開啟文件／匯出PDF／驗證），頁面可即時顯示進度與錯誤階段。
- 選擇OfficeBridgeData時自動送出**不含文件的橋接測試**。收到DONE才顯示已連通；9秒沒有回覆會要求確認CMD視窗、腳本執行政策及所選資料夾。
- 保留原本ZIP「來文」／主文優先／ATTCH數字排序及純PDF離線合併。
- 不需自行編譯EXE，使用已安裝的Microsoft Office與Windows內建cscript。仍須符合機關允許的本機腳本執行政策。

## 經驗證
- Node單元測試：ZIP排序、PDF合併、錯誤提示、公文抬頭文字解析。
- Windows實際cscript.exe：VBScript語法執行、非法來源拒絕、空白連線測試回覆DONE。
- **真實Microsoft Edge離線HTML**：開啟ZIP、拖曳加入PDF、手動調序、合併成功。

## 未完成的實機驗證
- GitHub CI沒有安裝Word／Excel／PowerPoint，所以**無法證明Office COM文件實際轉成PDF已修復**。若仍失敗，網頁會列出具體Office階段與錯誤碼，請回報該訊息。
- 無法保證Apex One不再攔截腳本；遇到防護警示應立即停止，不能停用或規避防護。
- 主文是影像掃描或使用不支援的PDF字型時，機關／文號辨識可能失敗，保留手動命名。
- 本版仍須由使用者按「儲存合併PDF」，不會自動寫回原ZIP資料夾；純瀏覽器沒有授權前不能擅自存取檔案系統。
- PDF合併不保證保留數位簽章、書籤、互動表單等；請保留公文原始檔並核對內容。
