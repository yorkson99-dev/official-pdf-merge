# 公文 PDF 快合｜Win32 原生免安裝工具

針對 Windows 10／11（x64）公務電腦設計的獨立 PDF 合併工具。

## 系統需求與執行方式

- **原生 Win32 視窗**（傳統 Windows 按鈕、清單與開啟／儲存對話框）。
- 產生單一約 2.4 MB 的 `公文PDF快合.exe`，**執行時不需要安裝 Go、Python、Java、.NET、套件或瀏覽器執行環境**。
- PDF 和 ZIP 全程本機離線處理，不上傳公文內容。
- EXE 未經程式碼簽章。機關電腦可能因應用程式控管政策禁止執行；須由資訊管理單位依法規與機關程序審核，請勿繞過管制。
- 開發／重新建置在 GitHub Actions 上進行；**公務電腦只下載已建置的 EXE**。

## 介面與操作

**預設「公文 ZIP」模式：拖入即輸出，無須再點擊。**

1. 直接把一份公文 ZIP 拖入程式視窗，或按「選擇 ZIP…」。
2. 程式在背景分析、合併並儲存至 **ZIP 所在資料夾**；沒有確認或另存對話框，完成後僅在狀態列顯示輸出檔名。
3. 只取 `來文` 資料夾中無 `ATTCH` 後綴的主文及同識別前綴的 `_ATTCH1`、`_ATTCH2` ……，順序是主文、附件編號由小至大。
4. 排除 `opinion`、`(before)`、`(after)`、`合併版` 與整個 `稿` 資料夾。
5. 預設命名為「機關公文.pdf」或「機關公文及其附件.pdf」；可事先勾選「完整日期、文號命名」，生成「機關＋發文日期＋發文字號＋函.pdf」。
6. 若 PDF 文字層無法辨識必要欄位，輸出「原 ZIP 檔名_來文資料待確認.pdf」，並在介面提示待核對，**不會猜測來文機關**。
7. 如同名 PDF 已存在，自動使用 ` (2)`、` (3)` 等尾碼，絕不覆寫原始 PDF 或 ZIP。

**「一般 PDF」模式：需人工決定順序。** 切換至「一般 PDF」，加入／拖入 PDF，使用清單拖動、上移／下移來確定順序。需要時可按「桌面直排／橫排」背景讀取桌面位置（這個動作不會在每次加入 PDF 時自動執行）。按「合併 PDF…」時才會出現存檔對話框。

兩種模式共用一個視窗，但輸入流程互不混用；ZIP 分析、檔案合併和桌面圖示查詢均在背景工作，不會阻擋一般視窗操作。

## 編譯

採 **純 Go 標準函式庫 + Win32 API**（呼叫 Windows 系統內建 DLL），沒有外部依賴。

```powershell
go test ./...
$env:GOOS="windows"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go build -trimpath -ldflags="-H=windowsgui -s -w" -o "公文PDF快合.exe" .
```

編譯作業由 GitHub Actions 執行，終端使用者不用在電腦上執行這些命令。

## 注意

- PDF 合併不保證保留數位簽章效力、互動表單、書籤與 PDF 內嵌附件，請保留來源檔，重要公務文件須核對輸出。
- 自動命名依可擷取文字層解析；影像式 PDF 或特殊編碼會使用「來文資料待確認」的檔名，請使用者核對。
- PDF 合併器偏重效率而非涵蓋所有 PDF 格式；若遇到無法支援的輸入，會停止合併並回報錯誤。
- 專案中的測試 PDF 均為合成資料，不包含實際公文內容。
- 已通過 GitHub Windows Runner 的 EXE 啟動、合成公文 ZIP 自動合併、輸出狀態回報及完成後連續切換模式測試；尚未於使用者的公務電腦完成實機驗證。

## 來源檔案與授權

Windows 入口為 `main_windows.go`，主文解析為 `lettertext.go`，公文 ZIP 規則為 `zipmerge.go`，PDF 合併核心為 `pdfmerge.go`。

程式僅供依機關資訊安全政策核可後使用。
